# 科研英语素材 v1

本目录包含 4 门原创课程（每门 60 句）、Monash 中英词表，以及配套 Andrew 音频。课程与词表采用统一的 `format/title/domain/level/tags/description/source` 属性；难度为 1–5 个 `★` 或 `null`（未评级）。

`catalog.json` 是固定下载入口，`v1/catalog.json` 是对应版本的相对目录。目录里的公共属性与正文一致，`count` 和 `sha256` 均由文件生成。`research-english-240-import.json` 可用于一次导入四门课程。

素材编辑源和构建脚本位于科研小盒仓库的 `materials/english/`。课程星级和标签已按新规范直接整理；现有本机 ID 和学习记录保留。配套音频内容没有改变。

本地生成不等于网站部署。更新时须一起提交目录与其引用的素材文件；GitHub Pages 部署完成后，再在软件中刷新素材目录。正式分发后的后续内容版本使用新的版本路径。
