# 单词素材包

Monash 生物医学词表 · 中英：3290 个词条，含中文释义及原表英美音标。

来源：用户提供的 `monash_biomedical_glossary2_cn.xls`（3307 行词条），合并 17 个重复项。名称沿用输入文件；中文释义与音标保留原表内容，未另行修订。原始文件 SHA256 记录在 JSON 的 source 字段中。本包为学习用整理版，不代表 Monash 官方发布或审核。

在支持单词素材包的科研小盒开发版中，打开「科研英语 → 单词本 → 可选素材包」下载；也可将本目录的 JSON 下载后通过「导入单词本」导入。

`research-english/catalog.json` 的 `courses` 继续提供句子课程，新增的 `wordbooks` 提供单词素材，带词数、文件 SHA256 和规范化词条校验值。下载不包含用户学习记录。
